# 姜晓角色动效素材目录

将千问生成的 5 个状态视频放入本目录，命名如下：

| 文件名 | 状态 | 触发 |
|--------|------|------|
| `idle.webm` | 待机 | 空闲等待输入 |
| `thinking.webm` | 思考 | 收到 prompt，AI 推理 |
| `replying.webm` | 回复 | AI 流式输出 |
| `working.webm` | 工作 | 工具执行（读/写/搜索/命令） |
| `error.webm` | 报错 | 出现错误 |

要求：
- 9:16 竖版
- 透明背景（WebM alpha）或深色纯底
- 首尾帧一致的无缝循环
- 建议体积 < 2MB/段（UI 懒加载）

素材缺失时对应 `<video>` 静默隐藏，不影响功能。
